# Contributing

Murim Map Studio is in Foundation V0.

## Rules

1. GitHub is the source of truth for code, schemas, migrations and tests.
2. Product decisions and research live in the canonical Drive folder.
3. Never commit secrets, private player data or hidden world truth.
4. Domain rules must not live only inside React/Konva components.
5. Do not add new infrastructure, renderers or services without a measured requirement.
6. Every PR must keep `format:check`, `lint`, `typecheck`, `test` and `build` green once the lockfile is established.

## Branches

Use short-lived branches. Foundation work starts on `foundation/bootstrap-v0`.
