# Murim Map Studio

Ferramenta web de worldbuilding, mapa narrativo e autoria para um RPG Murim online.

## Estado

Fundação V0 em andamento. O primeiro objetivo é construir uma base reproduzível, modular e auditável antes de qualquer polimento visual do mapa.

## Fonte de verdade

- **GitHub:** código, migrations, schemas, testes e CI.
- **Drive canônico:** decisões de produto, arquitetura, pesquisa e handoffs.
- **Segredos/world truth:** nunca entram em repositório público.

> Não adicionar dados secretos do mundo, credenciais, chaves ou conteúdo privado de jogadores neste repositório.
